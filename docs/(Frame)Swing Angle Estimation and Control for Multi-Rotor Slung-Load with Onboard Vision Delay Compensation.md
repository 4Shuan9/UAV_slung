# Swing Angle Estimation and Control for Multi-Rotor Slung-Load with Onboard Vision Delay Compensation
# 面向机载视觉时延补偿的多旋翼吊挂负载摆角估计与控制

## Abstract （摘要）

**Keywords:** Multi-Rotor UAV, Slung-Load, Swing Angle Estimation, Onboard Vision, Delay Compensation, Forward Prediction
**关键词：** 多旋翼无人机，吊挂载荷，摆角估计，机载视觉，时延补偿，前向预测



## I. Introduction （引言）
### A. Background （研究背景）
* **多旋翼无人机吊挂系统有何应用价值与挑战？**
阐述其在应急物流、海洋拖拽等领域的灵活性；指出系统强耦合、欠驱动特性导致的“摆角抑制”难题是保障飞行安全的核心瓶颈。
* **为何选择基于角度反馈的闭环控制方案？**
对比输入整形、轨迹规划等开环方案对参数偏差和外部风扰的敏感性，引出闭环反馈控制在提升鲁棒性上的不可替代性，进而明确“摆角实时感知”的必要性。

### B. Related Work （相关工作）
* **传统行业及常规无人机方案有何局限？**
分析起重机编码器等方案的重量冗余，以及无人机附加IMU导致负载特性改变、动补系统受限于实验室环境、纯模型观测器易受气动干扰失效等问题
* **视觉方案的现状及其在实际飞行中的挑战是什么？**
肯定视觉方案轻量化、非接触的优势；针对性指出当前捷联视觉方案面临的机体位姿耦合（导致伪摆角）与反馈耗时滞后（破坏控制稳定性）两大未解难题
* **本文的研究动机与核心切入点是什么？**
针对上述痛点，提出一套集姿态解耦、动力学前向预测于一体的视觉摆角估计方案，旨在解决高动态飞行下的高保真状态反馈问题

### C. Main Contributions （本文贡献）
* **顺理成章地承接 B 节末尾抛出的痛点，简练地列出本文在“视觉解耦提取”和“延迟补偿估计”等方面的核心贡献**



## II. System Modeling and Coordinate Decoupling （系统建模与坐标系解耦）
通过无人机自身的姿态信息，将 **“固定在机体上随动”** 的相机画面，转化为 **“参考世界坐标系”** 的摆角
### A. System Dynamics Model （系统动力学模型）
* 将空间中 **三维摆角** 解耦为 **双轴单摆** 微分方程，描述无人机加速度 **$a_x, a_y$** 与负载摆角 **$\theta_x,\theta_y$** 之间的关系，推导出负载受迫单摆方程：**$\ddot{\theta} = -\frac{g}{L}\sin\theta - \frac{1}{L}a\cos\theta$**

### B. Onboard Vision Projection （机载视觉投影）
* **针孔相机模型** + **机载视觉特性**，描述负载质心从 **图像像素坐标 $(u, v)$** 转换到相机坐标系下的方向向量，最终实现相机归一化坐标到 **机体坐标系 $V_{body}$** 的映射

### C. Decoupling via Attitude Compensation （基于姿态补偿的坐标解耦）
* 利用无人机 **姿态四元数 $q$**，将 **机体坐标系$V_{body}$** 旋转至 **世界坐标系 $V_{world}$**，通过此变换可以 **消除无人机自身俯仰/滚转产生的“伪摆角”**



## III. Swing Angle Calculation and Delay Compensation （摆角解算与时延补偿）
解决图像处理的 **“晚”** 与数据预测的 **“准”** 问题
### A. Visual Swing Angle Calculation （视觉摆角解算）
* 说明基于 **OpenCV 的标志物提取目标**，并结合上文的 $V_{world}$，通过 **反三角函数** 解算出 $X-Z$ 和 $Y-Z$ 轴的观测摆角

### B. Dynamic-Based Forward Prediction （基于动力学的前向预测）
* 定量分析从快门曝光、图像传输到算法输出的 **处理耗时 $\Delta t$**
* 利用 **II-A 节的动力学模型**，根据历史时刻的摆角状态和无人机当前的运动趋势，将 **$\Delta t$ 前的“旧摆角”** 推进预测为 **“当前时刻摆角”**

### C. Error Injection and State Update （误差注入与状态更新） 
* 视觉帧到达时，由于 **累积误差和模型不确定性**，预测值与观测值会有偏差。写出状态更新方程：$\theta_{new} = \theta_{pred} + K \cdot e$，说明利用 **残差修正当前的估计状态**。

### D. Closed-loop Anti-swing Controller （闭环抑摆控制器）
* 简要给出一个经典的 **速度前馈** + **摆角 PD 控制器**。指出该控制器的 **输入$\theta_x,\theta_y$** 是 **经过补偿的、无相位滞后** 的连续摆角信号，说明为何经过 **预测补偿后的摆角能显著提升控制器的相位裕度，避免系统发散**


## IV. Simulation Results and Analysis （仿真结果与分析）
### A. Simulation Setup （仿真环境配置）
* 描述基于 ROS 2, PX4 和 Gazebo 的仿真架构，包括 **x500 机体模型、下视相机参数和20段的柔性绳索**

### B. Accuracy and Delay Evaluation （精度与延迟评估）
* 分别对比 **大/小角度** 悬停下 **视觉解算值 cv，补偿后估值 cv_comp 与真值 truth** 的 **差值、均方根**，验证姿态解耦的准确性
* 展示未补偿信号在波峰波谷处的 **“滞后时间”**，并展现补偿后曲线与真值的贴合程度

### C. Anti-swing Flight Verification （抑摆飞行验证）
* 利用 **方型/8字型轨迹** 对比 **“未补偿摆角闭环（发散或震荡）”与“补偿后摆角闭环（迅速收敛）”** 的 **飞行轨迹与摆角收敛速度**



## V. Conclusion （结论）
* **提出了一种基于机载单目视觉的多旋翼吊挂摆角估计方法，通过坐标系变换实现了机体姿态与视觉摆角的解耦，并结合动力学模型前向预测，有效补偿了视觉处理带来的系统时延**
* **局限性与展望：**
    1.频率限制： 最终估计频率受限于相机原生帧率（25Hz），响应带宽仍有提升空间；
    2.模型简化： 前向预测基于理想刚性单摆模型，对极端机动下的柔性形变未作深度建模；
    3.缺乏实飞： 目前仅在仿真环境闭环，尚未评估真实风扰和复杂光照条件下的鲁棒性。
