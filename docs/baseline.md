## 精度边界

- 自由摆动时机体也会运动。本次横滚峰峰值约22.2°，横滚角速度RMS约20.2°/s；不应将PX4 Hold理解为机体绝对静止。
- 未发现本轮磁力计单位、轴向、地磁或采样时戳接口异常。原始传感器与PX4日志匹配后，自由摆动209条、八字156条磁力计及陀螺仪样本的采样时戳差均为0 ms。两项测试的统计窗口内没有姿态重置或磁力计创新拒收，日志未报告磁场/磁融合故障。
- PX4姿态仍有动态残差，尤其航向残差会在大摆动下串入小横向分量。本次自由摆动的横滚/俯仰/航向相对旋转残差RMSE约0.039 / 0.086 / 0.451°；同一像素仅在离线改用真值姿态后，视觉RMSE约0.054 / 0.051°。实际程序没有使用真值姿态。
- 因此，本版适合作为**接口正确、主要八字工况可重复、误差边界已记录的对照基准**；不支持“所有工况均达到0.02°”或“所有输出零延迟”的结论。大摆动的小横向分量精度仍是后续可研究的问题。
- 自由摆动属于压力工况，当前由系统自然振荡产生，不是已知输入的严格扫频辨识。姿态残差与晃动幅值并非一一对应，不能据此认定PX4 EKF2数值计算故障。
- 保留各观测器原有ZOH、历史处理与动态滞后，不用曲线对齐隐藏延迟。本轮正常降落也不构成对所有接触姿态稳定性的保证。
