# 观测器与 ADRC 参数选型报告

2026-10-22。当前正式基线已确认：主链路为 ESO_delay＋ADRC，EKF3＋ADRC 为配套参照。下列选定参数与正式 YAML、默认 launch 一致；未采用寻优候选，也未改变观测器或控制器结构。

## 1. 最终选择

**主链路采用当前 ESO_delay＋ADRC 正式参数；EKF3＋ADRC 保留原参数作配套参照。** 选择依据是持续绕行抑摆、跟踪精度和已完成的闭环验证，不将启动峰值下降等同于整体性能提升。

| 参数 | 主链路：ESO_delay＋ADRC | 配套参照：EKF3＋ADRC |
|---|---:|---:|
| 观测器带宽 ωₒ / (rad/s) | 8 | — |
| 连续过程噪声 qω / (rad²/s³) | — | 0.01 |
| 连续过程噪声 qf / (rad²/s⁵) | — | 0.05 |
| 有效视觉噪声标准差 / ° | — | 0.50 |
| 视觉时间标准差 / s | — | 0.002 |
| 控制带宽 ωc / (rad/s) | 3 | 3 |
| 摆角速度系数 ζ | 0.1 | 0.1 |
| 扰动补偿比例 γ | 0.5 | 1 |
| 抑摆映射 | 线性 | 原有非线性反演 |
| 扰动预限幅 / (rad/s²) | 启用，±0.3 | 关闭 |
| 扰动通道低通 | 启用，τ=0.05 s | 关闭 |
| 最终扰动补偿限幅 / (m/s²) | 启用，±0.15 | 关闭 |

共用设置：位置环 Kp=1.2、Kd=0.8；绳长 1 m，g=9.81 m/s²；每轴总水平加速度指令上限 ±3 m/s²；起飞高度 8 m、起飞速度 0.5 m/s。相机 25 Hz，加速度及观测状态目标 200 Hz，ADRC 50 Hz；积分最大步长 0.005 s。标准仿真 launch 使用同步输入时钟，其他时序、门限与保护设置保持原值。

八字固定 `eight_scale=8、omega=0.150`、切向偏航；周期约 41.89 s，理想参考最大水平速度约 1.70 m/s。

**ωₒ=6 及新 ADRC 候选均不纳入本次固定方案。** 前者降低观测波动，但闭环摆角未改善；后者主要改善启动峰值，同时增加跟踪代价。两者也未联合复验，不能直接拼接成“最优组合”。

## 2. 理论依据

ESO_delay 保留历史视觉 ZOH、历史加速度 ZOH、RK4 积分及当前状态预测。单轴模型与增益为：

\[
\dot\theta=\omega,\qquad
\dot\omega=-\frac{g}{l}\theta-\frac{a}{l}+f,\qquad
L=\begin{bmatrix}3\omega_o&3\omega_o^2-g/l&\omega_o^3\end{bmatrix}^{\mathsf T}.
\]

在该线性增广模型及连续测量的理想误差系统中，增益对应特征多项式 `(s+ωₒ)³`。ωₒ=8 时 L=[24,182.19,512]ᵀ。绳摆固有角频率约 3.13 rad/s；该带宽可作为响应与噪声的工程折中，不能由 25 Hz 或 200 Hz 单独推定。连续极点配置也不直接证明实际多速率、延迟系统稳定。

ESO 线性控制映射在总指令限幅前为：

\[
u=K_p(r-p)-K_d\dot p+l(\omega_c^2-g/l)\hat\theta
 +2l\zeta\omega_c\hat\omega+F_{\rm used}.
\]

θ、ω 在控制计算中使用 rad、rad/s；f 单位为 rad/s²。ESO 的 f 依次经过原有预限幅、低通、lγ 换算及最终限幅，形成加速度补偿 Fused；γ=0.5 是部分补偿，不是完整扰动抵消。EKF3 保留其原有非线性反演，不能套用该线性映射描述全部实现。

对线性链路，假设完美状态、理想加速度跟踪、小摆角、无扰动且忽略延迟与饱和，位置环与摆角环耦合后的特征多项式为：

\[
s^4+(K_d+2\zeta\omega_c)s^3+(K_p+\omega_c^2)s^2
 +K_d(g/l)s+K_p(g/l).
\]

所选参数对应 `s⁴+1.4s³+10.2s²+7.848s+11.772`，满足四阶 Routh–Hurwitz 条件。因此 ζ=0.1 在该名义模型下有依据；ζ 是摆角速度通道调节量，并非整个闭环的实际阻尼比。此分析不包含 PX4 内环、观测误差及采样延迟，不构成实际闭环稳定性证明。

EKF3 保留非线性三状态模型、RK4、历史事件回放及原有创新检验。qω、qf 为连续噪声强度；有效测量方差还含时间不确定性项 `ω̂²σt²`。所选 0.50° 是当前模型与时序下的有效调参值，不代表相机实际噪声为 0.50°。

## 3. 实验依据

统一采用正式八字节点、相同名义初态和 PX4 参数，不加风、额外延迟或降帧。最终复验每个配置用两个种子各飞两圈，第二个种子反向测试顺序。实际起飞后初态仍有小差异。

### 观测器选参

下表来自观测器独立复验，控制参数均为原值。Eθ、Eω 为两轴合并、保留偏置的 RMSE；Df 为等效 5 ms 扰动状态增量 RMS，只表示波动。

| 配置 | Eθ / ° | Eω / (°/s) | Df / (10⁻³ rad/s²) | 真实总摆角 RMS / ° | 水平跟踪 RMSE / m |
|---|---:|---:|---:|---:|---:|
| ESO_delay ωₒ=8，选定 | 0.0583 | 0.1755 | 1.554 | 2.164 | 0.993 |
| ESO_delay ωₒ=6 | 0.0575 | 0.1685 | 0.770 | 2.190 | 0.986 |
| EKF3 qω=0.01，选定 | 0.0445 | 0.1594 | 0.578 | 2.166 | 1.019 |
| EKF3 qω=0.03 | 0.0439 | 0.1641 | 0.507 | 2.155 | 1.017 |

ESO ωₒ=6 的扰动增量约减半，但真实摆角增加约 1.2%；保留 8 作为持续抑摆基线。EKF3 增大 qω 的收益较小且角速度误差增加约 3%，保留 0.01。

### 控制器选参

以下来自另一批独立飞行，不能与上表视作同一次试验。RMS 为两个种子的算术平均，峰值取最大值；总摆角为绳方向相对竖直的真实倾角。

| 配置 | 总摆角 RMS / ° | 摆角峰值 / ° | 第二圈摆角 RMS / ° | 水平跟踪 RMSE / m |
|---|---:|---:|---:|---:|
| ESO_delay 原参数，选定 | 2.155 | 11.53 | 1.792 | 0.991 |
| ESO_delay 候选 | 2.111 | 9.33 | 1.818 | 1.063 |
| EKF3 原参数，选定 | 2.160 | 11.56 | 1.784 | 1.015 |
| EKF3 候选 | 2.091 | 8.62 | 1.815 | 1.081 |

ESO 候选为 ωc=3.5、ζ=0.1、γ=0.5、扰动低通 τ=0.025 s；EKF3 候选为 ωc=3.5、ζ=0.15、γ=1，其扰动低通仍关闭。观测器均保持本报告选定值。

候选启动峰值分别降低约 19% 和 25%，但第二圈摆角 RMS 增加约 1.4% 和 1.7%，跟踪 RMSE 增加约 7.3% 和 6.5%。虽满足此前跟踪代价不超过 20% 的筛选要求，仍不足以全面替代原参数。固定方案优先保留持续绕行与跟踪表现。

## 4. 搜索范围与验证口径

- 观测器：同输入 C++ 数学核心回放筛选，随后独立闭环验证。ESO ωₒ 搜索 4、5、6、7、8、9、10、12、15、20、25、30；EKF3 共 21 组，覆盖 qω={0.003,0.01,0.03}、qf={0.015,0.05,0.15}、视觉标准差={0.03,0.05,0.10,0.20,0.50}° 的部分组合。两类观测器共 8 次两圈复验。
- ADRC：按 ζ→γ→ωc→共用位置环→已有扰动低通顺序筛选，完成 27 次单圈筛选和 8 次两圈复验。ζ 覆盖 0.05～0.7，γ={0,0.5,1}，ωc={2.5,3,3.5}；未穷举联合参数。ESO 的 ωc=2.5、ζ=0.1 未通过名义模型预检，未飞；EKF3 的 ωc=2.5 实飞摆角明显恶化，未采用。
- 原始真值、视觉及观测状态按时间戳核验；跟踪相对实际已发布参考。统计不跨超过 20 ms 的真值缺口插值；角速度参考由连续真值段数值微分并剔除缺口边缘。回放时序不完全等同于 ROS 在线回调，优先采用独立闭环结果。
- 最终有效复验未记录到 PX4 failsafe、总加速度指令饱和或退出 CONTROL。状态平均频率约 199.8～199.9 Hz，但最长记录时间戳缺口约 65～68 ms，不能据此宣称严格实时。

## 5. 结论与适用范围

**所选方案是当前平台、1 m 绳长、25 Hz 视觉、固定八字下有名义理论依据及重复仿真支持的工程基线，不是全局最优参数，也未证明低频、大延迟或大摆角下的稳定边界。** 两种子和小幅性能差异不支持统计显著性结论；Df 降低不等于扰动估计更准确。两套配套控制映射与扰动处理不同，不能据表中数字直接排名观测器优劣。

传统 ESO、EKF2 和 PD 不在本轮最终选参范围内。当前仍有约 1 m 水平跟踪 RMSE 和轨迹启动峰值，下一步宜核验参考前馈及位置—摆角耦合控制，再评估低频、延迟条件；不继续堆叠未经验证的参数组合。
