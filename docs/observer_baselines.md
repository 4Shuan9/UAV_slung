# 四种观测器对照基准说明

## 1. 处理流程与时间处理

每个方向分别估计；输出角度为 °、角速度为 °/s、集总扰动为 rad/s²。名义输出频率均为 200 Hz，实际间隔仍受调度和仿真运行速度影响。

| 方法 | 状态与处理流程 | 时间处理与对照定位 |
|:---:|---|---|
| `eso` | 线性单摆模型；估计角度、角速度、集总扰动；最新视觉与加速度保持，固定步长 RK4 推进 LESO | 不使用输入采集时间做历史对齐或延迟补偿；输出盖本次更新时间戳。作为视觉 ZOH 的传统 ESO 基准 |
| `eso_delay` | 相同线性名义模型与 LESO 增益；保存带时间戳的加速度历史，推进历史 ESO，再以无视觉误差注入的动力学预测到当前时刻 | 在相邻图像采集时刻之间保持上一帧视觉值；新帧只从其采集时刻起生效，不立即跳变修正历史状态。按采集时间处理有序视觉帧，拒绝重复及乱序帧；不具备 EKF3 式乱序回放。作为历史视觉 ZOH＋状态预测的 ESO 基准 |
| `ekf2` | 非线性单摆模型，含阻尼；估计角度、角速度；固定步长欧拉预测，视觉到达时进行 Kalman 更新 | 不按视觉采集时间回溯，直接用到达的测量修正当前状态；无显式延迟补偿，输出盖本次更新时间戳。模型预测可减轻表观滞后，但不等于延迟补偿 |
| `ekf3` | 非线性单摆模型；估计角度、角速度、集总扰动及协方差；RK4 传播，视觉 Kalman 更新 | 按采集时间插入历史测量、回溯校正并重新传播，再预测到当前发布时刻。保留有限历史窗口、时间不确定性建模和创新门限。作为三状态延迟测量补偿 EKF 基准 |

ESO_delay 的约 27.5 ms 残余滞后可能与历史 ZOH、最新视觉误差的注入方式及观测动态共同有关，尚未用消融实验确定各项贡献；不把它视为已确认的时间戳错误，也不通过平移曲线消除。

## 2. 已测实时滞后

以下记录此前 60 s PX4 Hold 自由摆动实验，四种方法在同一飞行中并行运行，未开启本项目抑摆控制器；真值峰值约 East 1.67°、North 48.22°。本次整理没有重新飞行或重新计算，原始临时数据当前已不在原目录，数值作为此前实验记录保留。

评价在约 200 Hz 的统一时刻，取各方法**截至该时刻已收到的最新输出**与当前真值比较；纯视觉在到达之间保持不变。仅评价用真值可插值到评价时刻，估计值不使用未来数据、不平移、不去偏置。

| 输出 |等效滞后 |
|---|---:|
| 纯视觉（参照） | 约 39.5 ms |
| 传统 ESO | 约 40.5 ms |
| ESO_delay | 约 27.5 ms |
| EKF2 | 约 19.5 ms |
| EKF3 | 约 1.0 ms |
