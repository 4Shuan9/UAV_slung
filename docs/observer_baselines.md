# 四种观测器对照基准说明

## 处理流程与时间处理

各方法均估计 East／North 两个方向；角度为 °、角速度为 °/s、集总扰动为 rad/s²。观测器名义输出 200 Hz，视觉采集 25 Hz。

| 方法 | 状态与处理流程 | 时间处理与对照定位 |
|---|---|---|
| `eso` | 线性单摆模型；角度、角速度、扰动；RK4 推进 LESO | 最新视觉 ZOH 与最新加速度直接输入，不按采集时间对齐，不做显式延迟补偿 |
| `eso_delay` | 相同名义模型、LESO 增益与 RK4；历史时间对齐后，将新视觉 ZOH 并配对加速度，继续校正到当前时刻 | 相邻采集时刻之间用上一帧推进历史锚点；新视觉从其采集时刻起参与到当前的回放。每次发布从锚点回放，不改写锚点，不额外重复外推；重复及乱序帧不融合 |
| `ekf2` | 非线性单摆模型，含阻尼；角度、角速度；欧拉预测与视觉 Kalman 更新 | 视觉到达时直接修正当前状态，不按采集时间回溯，保留为无显式延迟补偿的对照组 |
| `ekf3` | 非线性单摆模型；角度、角速度、扰动及协方差；RK4 与视觉 Kalman 更新 | 按采集时间回溯校正、重新传播至当前；保留有限历史窗口、时间不确定性建模及创新门限 |

例如视觉在 90 ms 到达、采集戳为 65 ms：`eso_delay` 先用上一帧视觉和对应加速度推进至 65 ms，再保持新视觉 `θ(65 ms)`，继续运行 LESO 至 90 ms。后一段就是带视觉校正的状态外推；推进到当前不代表残余相位滞后为零。

## 当前版本实测延迟

2026-10-26 重新启动正式版本，在 8 m PX4 Hold 下同步运行四种观测器，未开启本项目抑摆控制器；不加风、额外延迟或降帧，不修改模型、观测器及控制参数。进入 Hold 后先留出 5 s，再统计连续 60 s。

真值峰值约 East **5.85°**、North **42.98°**。评价网格为 200 Hz，每个时刻只取**截至当时已收到的最新值**，纯视觉到达后保持；仅真值可按采集戳插值。误差及绘图不平移、不去偏置。

下表以变化较充分的 North 方向计算等效相位滞后：采用去均值相关搜索，步长 0.5 ms；正值表示落后真值。它是本次运动下的相位指标，不是固定通信延迟，也不保证换帧率或轨迹后数值不变。

| 输出 | North 等效相位滞后 | 相关系数 |
|---|---:|---:|
| 纯视觉（到达后 ZOH） | 29.5 ms | 0.99938 |
| 传统 ESO | 30.0 ms | 0.99998 |
| ESO_delay（新视觉 ZOH） | 22.0 ms | 0.99994 |
| EKF2 | 10.5 ms | 0.99999 |
| EKF3 | -1.5 ms | 0.99997 |

EKF3 的 −1.5 ms 表示本次相关搜索得到轻微相位超前，不是负通信延迟，也不能据此认定严格零延迟。

本表与两张图均来自同一次当前版本实测，替换旧版约 27.5 ms 的记录；不与此前不同飞行条件的数值混合计算改善幅度。时间戳年龄表示数据所指时刻距现在有多久，不能直接当成相位滞后。
