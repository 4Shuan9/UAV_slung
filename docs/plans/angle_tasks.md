# 正弦摆动与短时定角：
> **根据吊挂系统和现有控制链路的响应，提前离线推导飞机运动轨迹，再控制小球以指定方式摆动。**

## 1. 任务目标

| 命令 | 目标摆角 | 轨迹安排 |
|:---:|---|---|
| `sine` | ±30°、0.45 Hz 定频正弦，周期约 2.22 s | 平滑建立摆幅，约 14.44 s 后周期重复，直至手动停止 |
| `maneuver` | +20° 维持 1.5 s | 反向预摆、进入定角、反向回收；参考总长 19.5 s，定角段位于第 9–10.5 s |

## 2. 轨迹推导

给定目标摆角及其变化率，根据吊挂动力学反算挂点水平加速度，再积分得到速度和位置，并换算挂点与机体参考点之间的偏置。定高、绷紧绳、单平面近似下：

$$
a_{h,r}=-\frac{l\ddot\theta_r+g\sin\theta_r}{\cos\theta_r}
$$

其中，$l$ 为绳长，$\theta_r$ 为目标摆角，$a_{h,r}$ 为挂点水平加速度；正方向沿用工程定义。

**维持非零摆角需要持续水平加速度。**
定角时 $|a_{h,r}|=g\tan|\theta_r|$，20° 和 30° 分别需要约 3.57、5.66 m/s²，因此当前采用 20°／1.5 s 短时定角。该段速度变化约 5.35 m/s；计入预摆和回收后，完整参考的速度峰值约 6.16 m/s。

- **定角轨迹：** 预摆约 −10.24°，进入 +20° 并维持 1.5 s，随后反向回收，以调整速度和位移。
- **正弦轨迹：** 1 m 绳长的小角度自然频率约 0.50 Hz，选取邻近的 0.45 Hz，利用较小的挂点运动形成明显的周期摆动。

轨迹计算还考虑当前仿真控制链路的响应增益与滞后；正弦任务已进行 0.45 Hz 幅值、相位校准。更换频率或平台后需重新验证。

**加入竖直运动：** 后续若研究穿框，可先在前后和上下组成的单平面内规划飞机与负载的运动；需要侧向对准或避障时再考虑侧向运动。
设挂点竖直加速度 $a_{z,r}$ 向上为正，在绷紧绳、单平面近似且 $\cos\theta_r\ne0$ 时，水平加速度变为：

$$
a_{h,r}=-\frac{l\ddot\theta_r+(g+a_{z,r})\sin\theta_r}{\cos\theta_r}
$$

竖直加速度会改变摆动动力学，需联合设计高度、摆角和水平轨迹。当 $a_{z,r}=0$ 时，该式退化为上面的定高公式。

例如，按当前 1 m 绳长，假设框高度范围为 4.2–6.0 m，飞机接近时平滑上升；
某一时刻飞机高度约 5.5 m、摆角约 20°，负载高度约为 $5.5-1\cos20^\circ=4.56$ m。
若负载位于飞机后方，飞机先通过框平面，负载随后通过，穿越后再调整高度并抑制摆动。
还需检查飞机、绳索和负载全过程的净空，并约束速度、加速度及绳索张力；摆角持续时间由框尺寸、穿越速度和轨迹共同决定。

## 3. 程序实现

位置、速度、摆角及加速度指令提前存入 `angle_sine.csv` 和 `angle_hold.csv`，运行时以 50 Hz 插值读取，并依据观测器输出的摆角、角速度修正跟踪误差。

**原观测器、C++ 控制器及基准增益保持不变，角度任务在交互入口增加参考换算和误差反馈。**North 方向由摆角归零调整为目标摆角跟踪，保留 ADRC 扰动补偿；East 和高度方向沿用原控制链路。

| 参数 | 当前设置 |
|:---:|---|
| 已复验主链路 | ESO_delay＋ADRC；Gazebo 真值仅用于评价 |
| 摆角／角速度反馈系数 | 2.0／1.2，计算单位 rad、rad/s |
| 正弦位置／速度反馈系数 | 0.15／0.7，用于抑制漂移 |
| 定角位置／速度反馈系数 | 0／0，优先保证摆角跟踪 |
| 水平加速度指令限幅 | 普通任务各轴 ±3 m/s²；角度任务及其停止阶段各轴 ±4.5 m/s² |
| 角度参考速度上限 | 6.2 m/s，超限拒绝启动；实际速度仍可能超调 |

统一入口为 `offboard_console.py`，轨迹读取与换算位于 `offboard_reference.py`，角度反馈参数位于 `config/angle_tasks/feedback.yaml`。两份 CSV 为运行所需的离线轨迹表。

## 5. 启动与操作

加载 ROS 环境、打开 QGC，在三个终端分别启动：

```bash
ros2 launch slung_ctrl sim.launch.py
ros2 launch slung_ctrl estimation.launch.py estimator:=all
ros2 launch slung_ctrl offboard.launch.py
```

`takeoff` 升至 8 m 原点并稳定后，执行 `sine` 或 `maneuver`；定角任务结束后自动制动、返回原点。

| 命令 | 功能 |
|---|---|
| `pause` | 平滑停止并保持抑摆；八字保存进度，角度任务取消进度 |
| `resume` | 恢复暂停的位置任务；角度任务需回原点重新启动 |
| `control off` | 仅在停稳后关闭抑摆，位置控制保留；新任务自动开启抑摆 |
| `reset` | 清除任务及暂停记录，平滑停止并就地抑摆悬停 |
| `home` | 清除任务，平滑停止后返回起飞完成点，开启抑摆 |
| `land` | 降落，等待上锁后退出 |

角度任务取消后，先执行 `home`，稳定后重新开始。制动过程中可能出现反向摆动。本次复验已覆盖起飞、任务执行与停止、八字暂停恢复、组合切换和降落；其他组合的角度跟踪精度尚未逐一评估。
