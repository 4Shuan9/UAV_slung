# EKF3：文献比较与研究路线

**EKF3值得继续作为论文方案发展。目前没有依据因为“别人用过EKF”，就判断我们的整体工作重复或应该放弃。**
应比较的是：各自依赖哪些传感器、估计什么、怎样处理迟到的数据，以及最终完成了什么任务。

现有工作既有可借鉴的成果，也有各自没有覆盖的问题。我们的优势同样需要用对照实验说明，不能仅凭仿真曲线重合，就认定已经优于已有实机系统。

## 1. 我们现在研究的是什么

目标是：**利用现有飞控状态与低频视觉，用简单的模型估计当前吊载状态，让这些信息能够支撑实际控制，并研究视觉变慢、延迟增大后还能做到什么。**

| 项目 | 当前情况 |
|---|---|
| 传感器与输入 | 下视相机给出摆角；视觉解算使用按采集时间对齐的PX4估计姿态；模型使用PX4输出的水平加速度，不直接依赖推力指令或电机转速 |
| 估计状态 | East、North各估计摆角、角速度、集总扰动三个状态 |
| 模型 | 分轴非线性摆模型，绳长固定；与完整三维耦合模型有区别 |
| 时间处理 | 视觉按采集时刻校正历史状态，再用后续加速度重算，输出当前状态；已有时间不确定性修正 |
| 频率 | 当前视觉约25 Hz，状态输出约200 Hz；两帧之间主要靠模型和加速度推进 |
| 控制验证 | 已有仿真抑摆、八字及指定摆动任务；角度任务重点复验链路为ESO_delay＋ADRC，EKF3同步输出估计，不能全部算作EKF3闭环成果 |
| 自主性 | 当前在线控制与视觉解算不直接读取Gazebo真值，真值用于评价；实机上飞控定位、姿态及吊载观测的整条链路仍需验证 |

数学模型与接口见[EKF3与ADRC](../theory/ekf3_adrc.md)，角度任务见[正弦摆动与短时定角](angle_tasks.md)。

## 2. 相关论文究竟完成了什么

以下以现有参考文献中的版本为依据。“未见专项验证”表示该文没有把这一问题作为明确的实验内容，不等于作者完全没有考虑，也不据此宣布研究空白。

### 2.1 Bisgaard等：简单模型与视觉估计，2007

[Vision Aided State Estimator for Helicopter Slung Load System](https://doi.org/10.3182/20070625-5-fr-2916.00073)

**传感器与模型：**下视相机观测吊载，借用直升机已有的IMU状态估计；系统图包含GPS、罗盘与IMU。使用加速度驱动的三维摆模型和UKF，并估计绳长，不需要在负载上安装传感器。

**时间处理与任务：**讨论缩小图像搜索区域以降低视觉处理延迟，但未见本文提出历史校正、重传播的延迟补偿方案。用实际飞行数据验证缓慢运动、绳长估计，以及负载短时离开视野后的模型预测；其重点是状态估计验证。

**与我们相比：**这是“简单模型＋基座加速度＋视觉”的重要先例，也说明这条技术路线有实际基础。我们采用固定绳长、分轴三状态EKF，增加集总扰动估计，拟重点研究低频与迟到视觉下的当前状态误差和闭环任务表现。

### 2.2 Tang等：视觉支撑三维大摆角机动，RA-L 2018

[Aggressive Flight With Suspended Payloads Using Vision-Based Control](https://doi.org/10.1109/LRA.2018.2793305)

**传感器与模型：**下视相机观测负载，IMU提供滚转、俯仰和角速度；**飞机位置、速度与偏航仍由Vicon动捕提供**。EKF估计三维绳索方向及其变化率，预测使用控制器计算的推力和姿态等信息，不只是估计一个标量摆角。

**时间处理与任务：**相机50 Hz、IMU100 Hz；处理视觉时缓存状态与输入，视觉结果得到后校正历史状态并重算，以补偿图像处理延迟。实机完成圆轨迹和绕障轨迹，绕障最大摆角约53.77°；**这个数是机动峰值，不是“指定53°并维持若干秒”的验证指标**。圆轨迹也包含持续的倾斜运动，不能说只是偶然把负载甩大。

**与我们相比：**它验证了负载相对状态估计与三维机动控制，但没有在该实验中完成整套无动捕反馈飞行。我们的飞控加速度输入、分轴扰动状态和拟研究的低帧率／延迟条件不同；同时，它已经做过延迟回放，不能把“历史校正再推进到现在”本身说成首次提出。

### 2.3 Li等：PCMPC，无动捕反馈的机载控制，ICRA 2021

[PCMPC: Perception-Constrained Model Predictive Control for Quadrotors with Suspended Loads using a Single Camera and IMU](https://arxiv.org/html/2107.10888v1)

**传感器与模型：**相机与IMU估计飞机运动，电机转速换算推力，三维绳索EKF估计负载状态。在线反馈不依赖动捕，Vicon用于实验真值；MPC同时考虑动力学、执行器和相机视野约束。

**时间处理与任务：**控制与估计以500 Hz运行，这不是相机帧率。实机完成不同速度的负载轨迹跟踪；本文未将视觉延迟补偿及帧率—延迟退化范围作为专项研究。

**与我们相比：**这是整套机载感知与控制的重要近邻，不能说无动捕吊挂飞行尚无人实现。我们的区别在于借用飞控已有状态、采用加速度驱动的低阶模型，并研究时序退化下的估计和任务能力；是否更省算力、对推力标定更不敏感，需要实测比较。

### 2.4 de Angelis与Giulietti：惯性测量与扰动增广EKF，Drones 2023

[An Improved Method for Swing State Estimation in Multirotor Slung Load Applications](https://www.mdpi.com/2504-446x/7/11/654)

**传感器与模型：**根据飞机—负载耦合动力学，用机载加速度间接重建摆角与角速度，并增广三方向气动力扰动。**视觉摆角不作为校正输入**；实机使用带GPS的Pixhawk，双轴电位器提供摆角评价数据。

**时间处理与任务：**实机估计运行100 Hz，电位器采样20 Hz；没有低频视觉迟到问题。完成有风条件下的户外飞行估计验证，文中明确说明实机试验没有主动稳定负载。

**与我们相比：**它是“EKF同时估计摆动和扰动”的直接先例，但输入与观测关系不同。我们用视觉直接校正摆角，并希望在视觉变慢或迟到时仍提供可靠的当前状态，还需证明这些估计对控制的实际收益。

### 2.5 Sarvaiya等：HPA-MPC，松绳—绷紧与可见性

[HPA-MPC: Hybrid Perception-Aware Nonlinear Model Predictive Control for Quadrotors with Suspended Loads](https://arxiv.org/html/2411.11982v1)（2024年预印本，文稿注明已获RA-L接收）

**传感器与模型：**实机有两台相机，一台用于视觉惯性定位，一台观察负载，结合IMU和指令推力；绳索EKF配合松绳／绷紧模式判断，在线估计和控制由机载系统完成。

**时间处理与任务：**负载视觉30 Hz，飞机状态预测500 Hz，MPC150 Hz，这三个频率不能混为一谈。实机验证负载轨迹跟踪、外力造成的松绳—绷紧转换和人机交互时的负载可见性；未见系统扫描视觉帧率与延迟的专项实验。

**与我们相比：**它解决的混合运动和视野约束比我们当前的绷紧绳模型更广，不能将其概括为普通抑摆。我们的研究可以集中在更小的模型、现有飞控接口和视觉时间误差，不必为了发表而复制整套混合MPC。

### 2.6 Zhang等：EKF＋LSTM补偿模型误差，Scientific Reports 2026

[Residual-learning-enhanced extended Kalman filter for real-time swing angle estimation in quadrotor-suspended-payload systems](https://www.nature.com/articles/s41598-026-49015-y)

**传感器与模型：**七状态EKF结合惯性比力与动力学估计摆动、扰动，LSTM学习估计残差；实机输入包括飞控IMU与推力指令，视频用于离线获取评价摆角，不是在线视觉校正。

**时间处理与任务：**仿真训练序列100 Hz，实机估计50 Hz；网络推理耗时不等于视觉传输延迟补偿。完成仿真和手动飞行估计验证，户外评价由同步视频后处理获得，机动限制在大致平行于相机成像面的平面内；接入主动抑摆闭环被列为后续工作。

**与我们相比：**它证明学习修正模型残差可以改善估计；我们的路线不需要训练，使用视觉摆角校正并处理采集时间。值得比较的是精度、训练依赖、计算开销和闭环任务表现，不能仅凭“不用神经网络”认定更优。

### 2.7 Fatehi与Huang：不规则、迟到测量的融合，JPC 2017

[Kalman Filtering Approach to Multi-rate Information Fusion in the Presence of Irregular Sampling Rate and Variable Measurement Delay](https://doi.org/10.1016/j.jprocont.2017.02.010)

**传感器与模型：**面向工业过程，把快速常规测量与低频、高精度的实验室分析数据融合，使用两个滤波器并处理估计误差之间的相关性，不涉及飞机或吊载传感器。

**时间处理与任务：**不规则采样和可变延迟就是核心问题，论文提出延迟估计融合，并通过仿真、中试和工业案例验证。文中也讨论了历史校正与重新计算等已有方法；不能把所综述的方法都归为该文原创。

**与我们相比：**它提供时间处理方面的基础，但不是我们的吊载应用复现。我们把高频加速度作为模型输入、低频视觉作为状态校正，另需面对非线性摆动、模型残差及闭环控制要求。

### 2.8 Sun等：惯性与延迟视觉定位，Sensors 2023

[Real-Time Optimal States Estimation with Inertial and Delayed Visual Measurements for Unmanned Aerial Vehicles](https://www.mdpi.com/1424-8220/23/22/9074)

**传感器与模型：**相机、IMU和下视超声测高用于飞机位置与速度估计；图像无线传到地面PC处理，再把结果传回机上。固定相机跟踪系统用于评价，所以“机载状态估计”不等于所有视觉计算都在机上。

**时间处理与任务：**惯性、估计和控制100 Hz，视觉处理周期设为160 ms，总视觉延迟约200 ms；通过缓存对齐并预测当前状态，采用固定处理周期简化补偿。做了飞行状态估计验证，并用离线数据处理比较150–400 ms延迟下的误差。

**与我们相比：**这与我们的多速率、迟到视觉问题很相关，说明“延迟增大后误差怎样变化”也已有研究。区别是它估计飞机平移状态；我们要进一步研究吊载摆动、集总扰动及指定任务的成功条件，而非只重复一张延迟—RMSE曲线。

## 3. 怎样客观评价我们的创新空间

**EKF是一种工具。使用相同工具，既不自动构成重复，也不自动构成创新。**应看研究问题、具体处理方法和证据是否形成了新的结果。

| 可研究的方向 | 与已有工作的区别 | 需要给出的证据 |
|---|---|---|
| 低阶模型能否支撑可靠观测 | 借用飞控加速度，分轴估计摆角、角速度和集总扰动，减少对完整耦合模型及推力信息的直接依赖 | 与完整模型、无扰动增广模型比较精度、耗时及参数敏感性；说明大摆角、双轴和竖直运动下的范围 |
| 迟到视觉下的当前状态重建 | 在具体吊挂系统中，把视觉采集时间、输入时间和状态传播处理一致 | 与不补偿、只对齐不推进、简单实时外推比较；说明误差与剩余滞后来自哪里 |
| 观测质量怎样决定任务能力 | 将帧率、延迟和模型误差与抑摆、八字、正弦、短时定角联系起来 | 给出任务误差和成功／失败条件，固定其余控制设置，分清观测器与轨迹设计各自的贡献 |

**最值得优先做的是把上述三点串成一条主线，而不是继续增加模块。**已写进代码的处理也可以是论文方法的一部分；它有没有创新性，要看与文献的实质区别和验证结果，不能因为“已经实现了”就排除在贡献之外。

需要同样公平地保留几项边界：

- **不用动捕反馈已有先例**，但仍是本平台应该保留并验证的实际价值；无需为了追求“首次”而否定其意义。户外定位也可以使用GPS，不要求所有平台采用同一种定位方式。
- **达到某个峰值、持续周期摆动、指定角度保持一段时间是不同任务。**后两者应报告幅值、相位、保持误差和退出过程，不能只比谁的最大角度大；当前20°／1.5秒仿真结果也不直接等于新的控制理论。
- **分轴模型的扰动项可能吸收耦合、输入误差和其他未建模影响**，尚不能直接当成准确测得的风力。
- **仿真误差和别人的实机误差不能直接排名。**200 Hz输出也不等于200 Hz独立视觉信息，要评价实际收到的当前输出与当前真值的差距。

## 4. 下一步怎么做，规模保持适中

先冻结观测器和控制参数，分开验证各项处理的作用；需要改进时再针对主要问题动手。

| 步骤 | 具体工作 | 要回答的问题 |
|---|---|---|
| 1. 同模型对照 | 在相同三状态EKF上，比较关闭时间补偿、只对齐历史状态、完整推进到当前；加入纯视觉ZOH和可实时运行的简单外推 | 收益到底来自哪一步？现有EKF2与EKF3同时存在多项差异，不能代替这组对照 |
| 2. 少量条件初筛 | 视觉25、15、10、5 Hz；额外延迟0、40、80、160 ms，先分别变化，再选关键点组合测试 | 误差和滞后从哪里开始明显恶化？另记链路原有延迟，区分到达抖动与采集戳误差 |
| 3. 模型检查 | 比较有／无扰动状态；选少量单平面、双轴和竖直运动，与完整模型对照 | 简化和扰动增广各自带来多少收益、代价？ |
| 4. 闭环任务 | 在相同任务、初始条件与控制设置下接入不同估计；先做八字、定频正弦和短时定角 | 估计改善是否真的让任务更准、更稳定？定角同时记录所需速度、加速度与空间 |
| 5. 关键条件复验 | 重复关键实验，随后开展实机验证；动捕或独立视频可以只用于评价 | 结果是否可重复，是否能迁移到实际传感器和飞控？ |

以上帧率与延迟只是建议实验点，不是已经验证的能力范围。任务成功标准应在测试前确定，例如定角允许误差、维持时长、轨迹误差和速度／加速度范围。

指标保持精简：**角度与角速度误差、偏置、相位滞后、真实摆动、轨迹误差、控制指令波动，以及计算耗时。**关键条件下再检查估计给出的不确定性是否符合实际误差。评价不使用未来视觉数据，也不通过平移估计曲线消掉延迟。

## 5. 当前结论

**继续研究EKF3有合理空间，不需要因为已有论文使用EKF就提前放弃，也不必把现有方案全部推倒重来。**我们的候选价值是：用较小的模型和现有飞控信息，处理低频、迟到视觉，解释它在指定吊载任务中何时足够、何时不够，并验证改进确实有用。

仅把几个现成模块接起来、展示一次效果，论证会偏弱；如果能说明明确的误差来源，给出相应处理、适用条件和可重复的任务收益，就有更完整的论文内容。**最终判断依据是具体差异与实验结果，而不是EKF这个名字，也不是对某篇论文的整体高低评价。**
