# EKF3：研究现状与方案

> **基于飞控状态与低频视觉，构建低阶扰动增广 EKF，重建当前吊载状态，并研究视觉帧率、延迟与模型误差对估计及控制任务的影响。**

## 1. 本系统研究现状

| 项目 | 当前实现 |
|---|---|
| 输入信息 | 下视视觉摆角、PX4 水平加速度；视觉解算使用按采集时间对齐的 PX4 估计姿态 |
| 状态与模型 | East、North 分别采用非线性三状态模型，估计摆角、角速度和集总扰动；绳长固定 |
| 时间处理 | 按视觉采集时刻校正历史状态，利用后续加速度重传播至当前；包含时间不确定性修正 |
| 基础对照 | EKF2 保留两状态和无时间补偿；名义模型、RK4、共有噪声、初始化与更新方式对齐 EKF3，用于比较整套升级的收益 |
| 更新频率 | 视觉约 25 Hz，状态输出约 200 Hz；帧间状态由模型与加速度推进 |
| 验证情况 | 已建立仿真抑摆、八字、正弦和定角任务；角度任务实验主控制链路为 ESO_delay ＋ ADRC，EKF3 同步估计 |
| 状态来源 | 在线估计与控制均使用 PX4 状态，Gazebo 真值用于评价；实机整链路验证尚待完成 |

模型与接口见 [EKF3 与 ADRC](../theory/ekf3_adrc.md)，角度任务见[正弦摆动与短时定角](angle_tasks.md)。

## 2. 关键文献与本项目区别

以下按传感器依赖、时间处理及验证任务比较。

### 2.1 简单模型与视觉估计：Bisgaard 等，2007

[Vision Aided State Estimator for Helicopter Slung Load System](https://doi.org/10.3182/20070625-5-fr-2916.00073)

Bisgaard 等采用**加速度驱动的三维摆模型与 UKF**，融合下视视觉，并在线估计绳长；飞机状态由已有 GPS、罗盘和 IMU 融合系统提供。研究通过实际飞行验证状态、绳长估计及负载离开视野后的预测，讨论降低视觉处理延迟，未见历史校正与重传播方案。**本项目采用固定绳长、分轴三状态 EKF，增加集总扰动估计，重点研究低频、延迟视觉下的当前状态重建与控制效果。**

### 2.2 视觉大摆角机动：Tang 等，RA-L 2018

[Aggressive Flight With Suspended Payloads Using Vision-Based Control](https://doi.org/10.1109/LRA.2018.2793305)

Tang 等利用下视相机、IMU 及推力驱动的 EKF 估计**三维绳索方向与变化率，飞机位置、速度和偏航仍由 Vicon 动捕提供**。相机 50 Hz、IMU 100 Hz，通过历史校正和重算补偿图像处理延迟，实机完成圆轨迹与绕障机动，最大摆角约 53.77°；该数值为机动峰值，非指定角度维持指标。**本项目使用飞控加速度驱动模型，关注分轴扰动增广、低帧率与延迟条件；整套无动捕反馈和指定摆角维持也应与其原任务分别比较。**

### 2.3 机载感知与控制：Li 等，PCMPC，ICRA 2021

[PCMPC: Perception-Constrained Model Predictive Control for Quadrotors with Suspended Loads using a Single Camera and IMU](https://arxiv.org/html/2107.10888v1)

Li 等结合**相机、IMU 和电机转速**估计飞机与负载状态，采用推力驱动的三维绳索 EKF 及带视野、执行器约束的 **MPC**。系统以 500 Hz 运行，实机完成不同速度的负载轨迹跟踪；**动捕用于真值评价，不参与在线反馈**，文中未专项分析视觉帧率与延迟退化。**本项目借用现有飞控状态，采用加速度驱动的低阶模型，拟比较计算开销、参数依赖及视觉时序退化下的任务能力。**

### 2.4 惯性测量与扰动估计：de Angelis 和 Giulietti，Drones 2023

[An Improved Method for Swing State Estimation in Multirotor Slung Load Applications](https://www.mdpi.com/2504-446x/7/11/654)

de Angelis 和 Giulietti 基于耦合动力学，利用**机载加速度间接估计摆角、角速度及三方向气动力扰动，无在线视觉校正**。实机采用带 GPS 的 Pixhawk，估计 100 Hz，双轴电位器以 20 Hz 提供评价摆角，完成有风户外飞行；实机试验未主动稳定负载，也不涉及视觉延迟。**本项目以视觉直接校正摆角，研究视觉变慢、迟到时的状态精度及闭环收益。**

### 2.5 松绳—绷紧与可见性：Sarvaiya 等，HPA-MPC

[HPA-MPC: Hybrid Perception-Aware Nonlinear Model Predictive Control for Quadrotors with Suspended Loads](https://arxiv.org/html/2411.11982v1)（2024 年预印本，注明已获 RA-L 接收）

Sarvaiya 等采用**两台相机、IMU 和指令推力**，分别完成飞机视觉惯性定位、负载状态估计及绳索模式判断。负载视觉 30 Hz、飞机状态预测 500 Hz、MPC 150 Hz，机载系统完成轨迹跟踪、松绳—绷紧转换和交互中的可见性控制，未见帧率—延迟扫描实验。**本项目当前限定绷紧绳，研究重点为低阶观测、飞控接口和测量时间误差，与混合动力学及可见性控制有所区别。**

### 2.6 学习修正模型误差：Zhang 等，Scientific Reports 2026

[Residual-learning-enhanced extended Kalman filter for real-time swing angle estimation in quadrotor-suspended-payload systems](https://www.nature.com/articles/s41598-026-49015-y)

Zhang 等采用**七状态 EKF 与 LSTM 残差修正**，实机输入为飞控 IMU 和推力指令，无在线视觉摆角校正。仿真训练序列 100 Hz、实机估计 50 Hz，完成手动飞行验证；户外真值由同步视频离线提取，机动限制在近似成像平面内，主动抑摆闭环列为后续工作，未研究迟到视觉融合。**本项目不依赖训练，通过视觉校正与时间处理估计当前状态，可比较精度、计算开销和闭环任务效果。**

### 2.7 惯性与延迟视觉定位：Sun 等，Sensors 2023

[Real-Time Optimal States Estimation with Inertial and Delayed Visual Measurements for Unmanned Aerial Vehicles](https://www.mdpi.com/1424-8220/23/22/9074)

Sun 等利用**相机、IMU 和超声测高估计飞机位置与速度**；视觉在地面 PC 处理后回传，固定相机系统用于评价。惯性、估计与控制 100 Hz，视觉周期 160 ms、总延迟约 200 ms，通过缓存对齐与状态预测补偿延迟，并离线比较 150–400 ms 延迟下的误差。**本项目研究对象为吊载摆动，还需分析扰动增广及帧率、延迟对指定任务成功条件的影响。**

## 3. 论文创新点应落在哪里

> **研究重点：利用飞控加速度驱动的低阶扰动增广模型，在低频、延迟视觉下准确重建当前吊载状态，并验证其对吊挂机动控制的支持作用。**

论文以**低阶观测方法和多速率状态重建**为主，控制任务用于验证观测收益。
帧率、延迟及机动范围作为适用条件，不单独扩展为传感器极限研究。

### 3.1 创新主张一：低阶模型下的摆动状态与模型残差联合估计

> **针对吊挂系统建模复杂、参数较多的问题，以飞控水平加速度驱动分轴摆模型，通过增广集总扰动补偿模型残差，在保留主要摆动信息的同时简化观测模型。**

每轴只估计摆角、角速度和集总扰动，直接利用视觉摆角校正；
观测模型不直接依赖电机转速、推力参数或学习网络。

应重点说明：**模型为什么可以简化、简化误差怎样被吸收，以及最终能保持多少精度**。
需要从完整动力学中明确分轴模型忽略的主要项，解释扰动状态的作用，并通过有／无扰动增广、分轴／完整模型对照，量化精度、参数敏感性和计算耗时。
两轴联合机动及竖直运动用于检查其适用范围。

现有 EKF3 已具备对应结构，理论文件也已有名义平衡点附近的局部可观测性分析；
后续重点补齐模型简化、残差定义的依据及针对性对照。
**主要贡献应落在精度保持机制及其验证，而非仅以三状态 EKF 的名称或形式作为创新。**

### 3.2 创新主张二：低频、延迟视觉下的当前状态重建

> **针对视觉更新慢、结果到达时已滞后的问题，将视觉校正放回采集时刻，再结合后续加速度推进状态与不确定性，连续重建当前摆角和角速度。**

应验证重点:**两帧视觉之间的状态是否准确、迟到测量能否及时改善当前输出**。
论文还应评价当时实际可获得的输出与当前真值之间的误差和滞后。

需要区分采样间隔、处理／传输延迟和采集时间误差，说明这些因素如何与加速度误差、模型残差共同影响预测。
采用同一模型比较无时间补偿、仅历史对齐、完整重传播及简单实时外推，分别统计帧间误差、角速度误差、剩余滞后和计算开销。

现有代码已包含历史回放和时间不确定性修正。
**论文主张应落在该低阶吊载模型的时序适配、误差处理及独立收益；
RK4、缓存和 200 Hz 发布属于实现方式。**

### 3.3 支撑验证：观测精度能否转化为机动控制效果

在相同轨迹、初始条件和控制设置下，将 EKF3 接入闭环，验证抑摆、八字、定频正弦及短时定角。
除估计误差外，记录真实摆角、跟踪误差和控制指令波动，说明观测改进对任务的实际影响。

**当前控制器优先作为验证工具，不另立新的控制器创新。**
EKF3 参与实际闭环的对应实验仍需补齐。
实机使用机载状态反馈，动捕或独立视频可仅用于误差评价。

上述两项为**拟形成的核心贡献**，闭环与实机实验提供支撑。

|:---:|---|---|
| 模型与误差推导 | 整理已有局部可观测性分析，补充完整模型到分轴模型的简化与集总残差依据 | 解释低阶结构如何保持精度 |

| 代表性时序实验 | 以当前 25 Hz 视觉为基准，选少量较低帧率、额外延迟及时间误差条件；评价实时帧间状态 | 验证低频与延迟条件下的精度和适用范围 |
| EKF3 闭环复验 | 固定控制设置，完成轨迹与摆角跟踪；先用同一 EKF 的不同处理方式对照 | 证明估计收益确实改善任务表现 |
| 实机验证 | 机载运行，独立真值评价，重复关键条件；报告精度、耗时及失败条件 | 验证实际传感器与飞控下的有效性 |

当前优先级：
- 补模型依据和同数据对照，再完成 EKF3 闭环与实机验证。
- 只有对照显示现有结构存在明确不足时，才调整必要模型项或误差处理；
- 重新设计控制器、引入 MPC 或开展穿窗，不作为本篇的前置要求。
