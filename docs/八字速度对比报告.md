# 八字轨迹速度对比报告

适用版本：本报告针对历史视觉线性插值版 `eso_fusion`；结果不直接适用于历史视觉 ZOH 版 `eso_delay`。

日期：2026-10-20—21。目的：在控制参数不变时，比较轨迹速度对估计、真实摆动和跟踪精度的影响。

## 实验条件

- Gazebo＋PX4 仿真，起飞高度 8 m、绳长 1 m；固定当前正式 ESO_fusion＋ADRC 闭环参数。EKF3 同时运行，仅用于估计对比。
- 位置环 kp=1.2、kd=0.8；ESO ωₒ=8 rad/s；抑摆 ωc=3 rad/s、ζ=0.1、扰动补偿比例 0.5。保留正式配置中的扰动通道低通及限幅；本轮没有调参或增加滤波。
- 四档各独立重启两次（Gazebo seed 42、43），每次悬停至仿真时间约 50 s，再执行两圈；共 8 次飞行、16 圈。使用同一份 PX4 参数和固定初始场景；起飞后的实际初态存在小幅差异。
- 不注入风、额外延迟或降帧；25 Hz 视觉、200 Hz 加速度输入和观测器、50 Hz 控制为标称配置。
- 实验使用工程外轨迹发布器，按**仿真时间**推进相位，约 50 Hz 发布位置与切向偏航，避免实时率影响工况。轨迹公式与正式节点相同，但正式节点按墙钟回调累加相位，因此非实时运行时不能直接套用本报告的周期。
- 使用工程外控制器副本，仅增加记录发布器，控制律保持一致；独立通信端口隔离 QGC 输入，未修改正式 PX4 参数。

## 轨迹与速度定义

相对中心的北/东参考位置为 $N=8\sin(\omega t)$、$E=4\sin(2\omega t)$，高度保持 8 m，偏航随轨迹切线。

$v_{\max}=8\sqrt{2}\omega$，$T=2\pi/\omega$。下表为参考速度；八字并非匀速运动。

- 起步从悬停切入非零参考速度（N/E 初始参考速度均为 8ω），偏航也切到轨迹切线；未额外添加平滑过渡。因此启动峰值受切入过程影响，第二圈用于辅助评价持续运行。
- 跟踪误差使用 PX4 位置采样时间与解析参考位置计算，不进行时间平移、去均值或事后轨迹拟合；水平 RMSE 为 √mean(eN²+eE²)。Gazebo 独立结果仅用运动前悬停数据校准固定原点差。
- 真实总倾角 α=atan(√(tan²θE+tan²θN))；报告 RMS(α)。指令统计为实际发送的水平加速度合成量。
- 8 次运行均已通过飞行模式、无 failsafe、控制器内部反馈有效性与参考公式检查。
- 两次重复仅用于工程复验，未进行显著性检验；结论适用于当前仿真平台、轨迹及固定控制参数，不能推论为实机安全速度或其他控制器的结论。

## 结论

- ω=0.125 相对 0.200：真实倾角 RMS 变化 -58.3%，水平跟踪 RMSE 变化 -40.9%，单圈时间增加 60.0%。
- ω=0.150 相对 0.200：真实倾角 RMS 变化 -42.6%，水平跟踪 RMSE 变化 -27.9%，单圈时间增加 33.3%。
- ω=0.175 相对 0.200：真实倾角 RMS 变化 -22.9%，水平跟踪 RMSE 变化 -14.6%，单圈时间增加 14.3%。
- 降速同时改变速度、加速度和任务时间，因此本对比用于选择运行工况，不能作为控制算法优于其他算法的证据；算法间比较应固定同一速度。

- 综合速度、倾角和跟踪误差，建议优先考虑 ω=0.150（最大参考速度约 1.70 m/s）；ω=0.125 更侧重精度，ω=0.175 更侧重效率。现行默认值已固定为 ω=0.150，当前 ESO_delay 配套参数与复验结果见 [参数选型报告](config/parameter_selection.md)。
- 实际速度峰值高于最大参考速度，包含启动过渡与闭环超调；“最大参考速度”不能当作实际速度上限。
